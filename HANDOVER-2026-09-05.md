# Handover — 5 September 2026

## Status and scope

This branch builds on `57fd8a4` and contains the development work from the
September 4–5 session. The game remains an unfinished alpha. The historical
45% estimate is not a measured release assessment.

Read this summary first. `HANDOFF.md` retains the detailed chronological record;
older “next steps” there may have been superseded by newer entries.

## Delivered

### Startup and build

- Fixed the undeclared `boreExag` that prevented startup.
- Added `tools/vite.mjs` to import Vite configuration directly, avoiding the
  restricted-Windows config-bundling failure.
- `npm run build` runs all registered checks and generates `dist/index.html`.
  Latest measured size is approximately 3.98 MB before compression.

### Rig assets and references

- Connected Blender MCP and authored the compact rotary head and split mast in
  separate scenes, preserving existing Blender scenes.
- Added GLB assets and authoring scripts. The rotary head has 8,556 triangles;
  the mast has 6,152. HIGH/MEDIUM load them at initialization; LOW and failed
  loading retain procedural alternatives.
- Preserved spindle/outlet animation anchors and the mast's lower/upper flex
  hierarchy. Clones own their geometry because batching disposes its inputs.
- Added method-aware rotary/percussion head selection, corrected starter rail
  placement and duplicate mast-end hardware, and reduced excessive metal normals.
- Real machine photo references and source limitations are documented in
  `research/19-oem-visual-pass.md` and `research/20-mast-photo-reference.md`.
  OEM photos are external references, not licensed game textures. Models are
  original fictional designs, not exact OEM replicas.
- The coffee cup/studio renders requested during the session are local outputs,
  not gameplay assets or part of this PR. Editable Blender files also remain in
  the session outputs; the repository contains GLBs and authoring scripts.

### Career, contracts and persistence

- Routed UI contract acceptance through progression so costs and eligibility
  are applied. Reaccepting the current job resumes without resetting progress.
- Prevented silent replacement of an active job. Abandonment now closes both
  the simulation and the career contract.
- Results offer **Next hole** until the contract is complete; the board uses
  progression's jobs, including rescue work.
- Retried randomized ground profiles when no reachable valid final bed exists,
  then used the nominal profile instead of silently choosing invalid ground.
- Protected good save backups from malformed primary saves, retained dirty
  state after failed writes for retries, and cleaned up visibility listeners.

### Jet grouting

- Replaced generic rotary fallback with pre-drill followed by jet-and-lift.
- Treatment requires grout delivery and rotation. Only the completed return
  pass emits completion; reaching bottom does not settle the job.
- Added relative soil erodibility and a withdrawal/delivery coverage score.
  Treatment quality now carries 50% of the final grade rather than zero.
- Updated HUD control/stage labels, rotary-head selection, dust-hood visibility,
  a simple procedural monitor with radial ports, and the VFX medium.
- Added a reusable translucent treated-interval marker in the geological
  section and corrected the lifting monitor's action anchor.
- Removed geology's incorrect 6m minimum contract target so 5m jobs align.

The process is based on Keller's jet-grouting description:
https://www.keller.com/expertise/techniques/jet-grouting
Rates, erodibility factors and scoring weights are gameplay tuning. The overlay
uses the existing exaggerated bore width; it does not predict physical diameter,
strength, permeability or grout volume. Nozzle blockage is not implemented.

## Verification

- `npm run build`: passes facts/data checks, model checks, career checks and jet
  tests. Covers 21 selectable methods and 18 rig builders for data/render mapping,
  not end-to-end playability of all combinations.
- `tools/check-career.mjs`: 24,000 seeded contracts, save recovery and retry,
  acceptance/resume/abandonment, and a real two-hole auger simulation through
  rod changes, payout, XP and contract completion.
- `tools/check-jet.mjs`: phase order, flow/rotation gates, single completion,
  monitor geometry, 30/120fps comparison, 5/20/60m clay jobs, soil response and
  excessive-withdrawal penalty.
- `node tools/stagepace.mjs --fps`: four existing HDD/raise-boring comparisons
  passed at 30 and 120fps with identical scheduled inputs.
- Browser inspections: production startup, board/details and active-job rejection,
  rig workshop, rotary-head switching, and a half-treated 20m section.
- Not verified: all-method career runs, mobile devices, full-session memory and
  performance, or complete visual correctness. Texture serialization warnings
  have been observed. Passing tests are not a release certification.

## Running and review

```sh
npm install
npm run dev
npm run build
npm run preview
```

Use the URL printed by Vite. Preview is configured for port 5179. In this session
the development server ran on 5180. Review pages are development-only:

- `/tools/rig-review.html`: rig/method inspection and rendering counters.
- `/tools/jet-section-review.html`: slider-controlled treatment visualization;
  does not modify career saves.

Blender scripts currently contain absolute session paths. Adjust `ROOT`/`OUT`
before reproducing assets elsewhere. The mast script reuses primitives from the
head script. No engine migration was performed; the game still uses Three.js.
